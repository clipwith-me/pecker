Incident Status Lifecycle

NEW → ACKNOWLEDGED → IN PROGRESS → RESOLVED → CLOSED

All transitions are server-validated against a typed transition map. REJECTED is available from NEW or ACKNOWLEDGED. RESOLVED → IN_PROGRESS rollback supported for re-investigation.

4. Map Architecture

Technology: MapLibre GL JS (MIT, free, no API key) + OpenFreeMap vector tiles (unlimited, free) + ESRI World Imagery for satellite.
All map services are 100% free with no usage limits — chosen after evaluating Google Maps ($7/1k loads), MapTiler (100k/mo cap), and Stadia Maps (200k/mo cap).

🗺️ Public Map (/map)

  • No login required — anyone can view
  • Vector tiles: streets, schools, hospitals, estates, businesses, roads at every zoom (up to z20)
  • 4 map styles: Streets, Bright, Minimal, Satellite
  • Incident clustering (supercluster via MapLibre source)
  • Severity-coloured pins: Low/Medium/High/Critical
  • Click pin → popup → public incident detail (/i/[id])
  • Location search via Nominatim (addresses, schools, landmarks)
  • Locate Me, Fullscreen, Scale bar, Navigation controls
  • Logged-in users see Dashboard + Report buttons in header

📍 Location Intelligence

  • GPS → Nominatim reverse geocode → human address (road, neighbourhood, city, state)
  • Address search → fly-to on map
  • lat/lng stored in DB, text description displayed
  • Default map centre auto-computed from incident cluster centroid
  • Public incident detail page (/i/[id]) — no login required, shows full info + media

5. Security Architecture

🔐 Authentication

  • NextAuth v5 with Credentials provider
  • JWT sessions — trustHost: true (Vercel alias support)
  • 30-day session maxAge (explicit)
  • bcryptjs cost=12 password hashing
  • Password policy: 8+ chars, uppercase, number

🛡 Authorization (RBAC)

  • RESIDENT — report incidents, view own, upvote, edit while NEW
  • RESPONDER — manage all incidents, assign, escalate, export CSV
  • ADMIN — everything + user management + dashboard stats
  • Role checked server-side on every protected API route
  • (app) layout enforces auth at the Next.js server level

✅ Input Validation

  • Zod schemas on all API inputs (server-side)
  • React Hook Form + Zod on all UI forms (client-side)
  • File type whitelist (JPEG/PNG/WebP + MP4/WebM/MOV)
  • 5 MB image / 50 MB video hard limits
  • Parameterised queries via Prisma (SQL injection proof)
  • Anonymous reports validated (guestName required)

📋 Audit Trail

  • Every status change, assignment, escalation and note logged
  • Immutable event log — append-only, never deleted
  • Actor + timestamp on every event
  • Visible to all stakeholders in the incident timeline
  • Anonymous reports flagged but still audited server-side

8. Key Architectural Decisions

DecisionWhy
Prisma enums → String fieldsAvoids enum migration friction on Neon; Zod enforces valid values at the API boundary
globalThis Prisma singletonPrevents connection pool exhaustion during Next.js hot-reload in development
MapLibre GL + OpenFreeMap (not Google Maps)Unlimited free usage, no API key, MIT licence, vector tiles with full POI/label detail
Nominatim for geocoding (not Google Places)Free, no key, adequate quality for community incident addresses
Anonymous system user patterngetOrCreateAnonymousUser() satisfies the reportedById FK constraint without nullable foreign key migration
trustHost: true on NextAuthRequired for Vercel alias URLs — without it, session cookies are rejected on the aliased domain
Public routes outside (app) group/map and /i/[id] are outside the (app) auth guard; logged-in users get contextual nav via useSession
MediaRecorder with live previewsrcObject on a <video> element streams camera feed in real-time during recording
Next.js 16.2.7 pinnedEarlier versions blocked by Vercel CVE policy; v17+ not yet stable
Tailwind v3 pinnedv4 is PostCSS-incompatible with all v3 component patterns used in the design system
useForm<any> for Zod .default() formsZod input/output type mismatch breaks the Resolver generic; <any> is the documented workaround
dynamic import renamed to lazyLoadAvoids name collision with Next.js export const dynamic = "force-dynamic" on the same page
